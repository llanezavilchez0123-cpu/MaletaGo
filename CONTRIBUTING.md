# Cómo colaborar

## Antes de empezar

1. Revisa el README y los requisitos.
2. Busca una incidencia existente o crea una que describa el cambio.
3. Si ya formas parte del repositorio, actualiza tu rama `main` antes de empezar.

## Ramas

No trabajes directamente en `main`. Crea una rama por tarea:

- `feature/nombre-corto` para una funcionalidad.
- `fix/nombre-corto` para corregir un error.
- `docs/nombre-corto` para documentación.

## Pull requests

Al terminar, abre un pull request hacia `main` e incluye:

- qué problema resuelve y qué cambió;
- cómo se probó;
- capturas si modifica pantallas;
- la incidencia relacionada.

Espera la revisión de otro integrante antes de integrar el cambio. No subas credenciales ni datos reales.
